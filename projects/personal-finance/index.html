Personal finance dashboard

I wanted one page that tells me where my money goes, which charges repeat every month, and how long a savings goal will take. This is that page, running on two years of made-up transactions.

Personal project, built on my own time. Everything runs in your browser on sample data generated from a seeded random number generator. None of it is my real financial data.

Monthly compounding: Bn = P(1 + i)n + C((1 + i)n − 1) ÷ i, where i is the annual return ÷ 12, n is the number of months, P is the starting balance and C is the monthly contribution. Time to target solves the same formula for n: n = ln((T·i + C) ÷ (P·i + C)) ÷ ln(1 + i).

How it works

A seeded generator writes 24 months of transactions for a salaried person in an invented US city: two paychecks a month with a raise halfway through, a yearly bonus, rent, groceries, dining, transport, subscriptions, travel and some odd one-offs. Each one only has a raw description like a bank export, for example POS PURCHASE GREENLEAF MARKET #0457.

I clean each description, then run it through a short list of keyword rules. The first rule that matches sets the category. Anything no rule matches stays uncategorised, and the page counts how many that is instead of guessing.

What this shows

I like building small tools that make my own decisions clearer, like seeing which charges quietly repeat or what one more hundred a month does over ten years. This page is how I approach that: simple rules I can read, numbers computed in front of you, and honest gaps where the rules do not know the answer.
